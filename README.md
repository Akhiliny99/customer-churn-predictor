Customer-churn-predictor
Built an end-to-end ML classification app predicting 
customer churn with ROC-AUC of 0.832.

What I did:
- Analyzed 7,043 real telecom customer records
- Handled imbalanced data using SMOTE
- Compared 6 models — Logistic Regression won over XGBoost
- Deployed as a live risk scoring web app

Tech: Python · Scikit-learn · SMOTE · Streamlit · Plotly
